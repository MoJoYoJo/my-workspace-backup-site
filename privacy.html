Privacy Policy

Last updated: November 14, 2026

Overview

My Workspace Backup is a personal, non-commercial backup application operated on a private server.

Google Drive access

The application uses the Google Drive API with the drive.file permission to create, access, verify and manage backup files created by the application.

Data storage

Backup archives contain application and project data and are encrypted before being uploaded to the connected Google Drive account. Authentication credentials are stored on the private application server.

Data sharing

Google user data accessed through the Google Drive API is not sold or used for advertising.

Retention and deletion

Backup files remain in the connected Google Drive account until they are deleted by the account owner or through the application's configured backup rotation. The user can revoke Google access through their Google Account settings.

Purpose

Google Drive access is used solely for backup storage, verification and recovery operations.
